CS180 Project 2: Images of the Russian Empire

Requirements: numpy, scikit-image

To run: python3 script.py

Change the `file_name` variable at the top of the script to process a
different image, and manually swap the align()/pyramid() calls at the
bottom of the script depending on which you want: align() for the
single-scale results (cathedral, monastery, tobolsk) and pyramid() for
everything else.
